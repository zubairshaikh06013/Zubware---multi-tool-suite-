# Free image optimization workflows — Zubware

Practical, shareable guidance for preparing web images without installing desktop software. These instructions are general best practices; compare the output visually before publishing.

## 1. Compress an image for a faster page

Open [Zubware Image Compressor](https://www.zubware.com/image-compressor).

1. Start with the original image rather than repeatedly compressing an already-compressed copy.
2. Choose an output size or compression level that fits your use case.
3. Preview the result at the size visitors will actually see.
4. Compare file size and readability, especially around text, fine lines, and faces.
5. Download the result and verify it on mobile and desktop.

**Tip:** Compression reduces transfer size, but large displayed dimensions, unnecessary images, and missing lazy loading can still slow a page.

## 2. Resize for a blog, website, or social post

Open [Zubware Image Resizer](https://www.zubware.com/image-resizer).

1. Decide the image's intended display dimensions before resizing.
2. Keep the original aspect ratio unless the destination specifically requires a crop.
3. Export at sufficient resolution for sharp display, but avoid oversized files.
4. Recheck important details after resizing and compression.

**Tip:** Resizing changes pixel dimensions; compression primarily targets file size. They solve different problems and can be combined.

## 3. Remove a photo background

Open [Zubware Background Remover](https://www.zubware.com/background-remover).

1. Choose a photo with a clearly distinguishable subject.
2. Remove the background and inspect fine edges, hair, and transparent areas.
3. Prefer a transparency-supporting format such as PNG when you need a transparent background.
4. Check the result on both light and dark backgrounds before using it in a design.

**Tip:** Automatic cutouts may require a second attempt with a better source photo. Do not assume every edge will be perfect.

## 4. Quick publishing checklist

- [ ] Image dimensions suit the page or platform.
- [ ] Text and key details remain readable.
- [ ] File size is reasonable for the use case.
- [ ] Alt text describes the image's meaning rather than stuffing keywords.
- [ ] Decorative images do not block the main content from loading.
- [ ] The exported image has been checked on a phone.
