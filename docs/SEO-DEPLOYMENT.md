# Cloudflare Pages Production Deployment & Redirect Architecture

## Production Canonical Domain
The official production canonical domain for Zubware is:
**`https://www.zubware.com`**

Because client-side Single Page Applications (React/Vite) cannot return HTTP 301 responses before JavaScript loads, all domain and protocol canonicalization must be enforced at the Cloudflare edge layer.

---

## Required Cloudflare Edge Redirect Rules

Navigate to **Cloudflare Dashboard → Rules → Redirect Rules** (or Page Rules) for `zubware.com` and configure the following 301 Permanent Redirects:

### 1. HTTP Apex to HTTPS WWW
- **Condition**: `(http.host eq "zubware.com" and http.request.scheme eq "http")`
- **Target URL**: `https://www.zubware.com/${path_and_query}`
- **Status Code**: `301 - Permanent Redirect`
- **Preserve Query String**: `Yes`

### 2. HTTP WWW to HTTPS WWW
- **Condition**: `(http.host eq "www.zubware.com" and http.request.scheme eq "http")`
- **Target URL**: `https://www.zubware.com/${path_and_query}`
- **Status Code**: `301 - Permanent Redirect`
- **Preserve Query String**: `Yes`

### 3. HTTPS Apex to HTTPS WWW
- **Condition**: `(http.host eq "zubware.com" and http.request.scheme eq "https")`
- **Target URL**: `https://www.zubware.com/${path_and_query}`
- **Status Code**: `301 - Permanent Redirect`
- **Preserve Query String**: `Yes`

### 4. Canonical Target (Status: 200 OK)
- **Target**: `https://www.zubware.com/*`
- Serves pre-rendered static HTML and assets generated by the Vite build pipeline (`dist/`).

---

## Security Headers
Security headers are served directly from `public/_headers` (copied to `dist/_headers` on build):
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: camera=(self), microphone=(), geolocation=()`
- `Strict-Transport-Security: max-age=31536000; includeSubDomains`
- `Content-Security-Policy: upgrade-insecure-requests`

## Verification Checklist
1. `curl -I http://zubware.com` → `301 Moved Permanently` to `https://www.zubware.com/`
2. `curl -I http://www.zubware.com` → `301 Moved Permanently` to `https://www.zubware.com/`
3. `curl -I https://zubware.com` → `301 Moved Permanently` to `https://www.zubware.com/`
4. `curl -I https://www.zubware.com/` → `200 OK`
5. `curl -I https://www.zubware.com/sitemap.xml` → `200 OK`
