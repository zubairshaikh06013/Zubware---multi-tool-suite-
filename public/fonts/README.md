# Self-hosted brand font

Plus Jakarta Sans, upright variable font (weights 200–800), distributed under the included SIL Open Font License. Original authors: The Plus Jakarta Sans Project Authors / Tokotype.

Source: https://github.com/google/fonts/tree/main/ofl/plusjakartasans
Downloaded source: https://raw.githubusercontent.com/google/fonts/main/ofl/plusjakartasans/PlusJakartaSans%5Bwght%5D.ttf

Source TTF SHA-256: `89b3fb38aa0d275d7a731d0d817a4f1622b316b4d7fbdedcf02ee9099ff68bc8`

The complete original font was converted without subsetting using fontTools TTFont with `flavor = 'woff2'` and Brotli. The WOFF2 filename contains the first 12 characters of its SHA-256 hash. The original license is in PlusJakartaSans-OFL.txt. No font build dependency is needed at runtime.
